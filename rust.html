Rust Learning

Getting Started

Install Rust, learn Cargo, and build your first program.

How do I install Rust and verify it works?

Use rustup (recommended):

# Windows (PowerShell)
winget install --id Rustlang.Rustup

# Verify
rustc --version
cargo --version

Create and run a project:

cargo new hello_rust
cd hello_rust
cargo run

What are the most useful Cargo commands?

  • cargo new / cargo init — create project
  • cargo build — compile
  • cargo run — build + run
  • cargo test — run tests
  • cargo fmt — format code (needs rustfmt)
  • cargo clippy — linting suggestions (needs clippy)
rustup component add rustfmt clippy

Rust Basics

Variables, mutability, functions, and control flow.

What’s the difference between let and let mut?

Bindings are immutable by default. Use mut when you need to change the value:

let x = 10;
// x = 11; // error

let mut y = 10;
y = 11; // ok

How do I handle errors without crashing?

Prefer Result and propagate errors with ?:

use std::fs;

fn read_config() -> Result<String, std::io::Error> {
    let text = fs::read_to_string("config.toml")?;
    Ok(text)
}

At the top-level, you can return Result from main:

fn main() -> Result<(), Box<dyn std::error::Error>> {
    println!("Hello");
    Ok(())
}

Ownership & Borrowing

The key Rust concept for memory safety without a GC.

What is ownership (in one minute)?

  • Every value has exactly one owner.
  • When the owner goes out of scope, the value is dropped.
  • Assigning/passing a value can move ownership (for types like String).
let a = String::from("hi");
let b = a; // move
// println!("{}", a); // error: a was moved

What are references and borrowing rules?

Borrow with references so you don’t move ownership:

fn len(s: &String) -> usize { s.len() }

let s = String::from("hello");
println!("{}", len(&s)); // s still usable

Rules (simplified):

  • Any number of immutable borrows: &T
  • At most one mutable borrow: &mut T
  • Cannot mix mutable and immutable borrows at the same time

Types & Data Modeling

Structs, enums, pattern matching, and traits.

When should I use struct vs enum?

Use struct for “all fields exist together”; use enum for “one of many variants”.

struct User {
    name: String,
    active: bool,
}

enum Payment {
    Cash,
    Card { last4: u16 },
    BankTransfer(String),
}

How does match help avoid bugs?

match is exhaustive: you must handle every possible case.

fn describe(p: Payment) -> String {
    match p {
        Payment::Cash => "cash".into(),
        Payment::Card { last4 } => format!("card ****{}", last4),
        Payment::BankTransfer(iban) => format!("bank {}", iban),
    }
}

Collections

The most common standard collections you’ll use daily.

What are the go-to collections in Rust?

  • Vec<T> — growable array
  • HashMap<K, V> — key/value map
  • HashSet<T> — unique items set
use std::collections::HashMap;

let mut counts = HashMap::new();
counts.insert("apples", 3);
counts.entry("apples").and_modify(|v| *v += 1);
