# Olympia iPhone App (Expo)

iPhone app quiz hard-level Vietnam-only using 500 questions in `data/questions.json`.

## Run

1. Open terminal in `iphone-app`
2. Install dependencies:
   - `npm install`
3. Start app:
   - `npm run start`
4. On iPhone, install **Expo Go** and scan the QR code.

## Notes

- App loads 20 random questions each session from the 500-question pool.
- Data source file: `data/questions.json`.
- You can publish to App Store later using EAS Build.
