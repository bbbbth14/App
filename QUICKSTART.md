## 🎮 How to Use Each Feature

### 🔍 Search (Ctrl+K)

```
1. Press Ctrl+K or Cmd+K
2. Type keywords
3. See highlighted matches
4. Questions filter in real-time
```

### 🎯 Quiz Mode

```
1. Click "Start Quiz Mode"
2. Choose: # questions, time limit, difficulty
3. Answer questions
4. Submit and see results
5. Review wrong answers
```

### 🎴 Flashcard Mode

```
1. Click "Flashcard Mode" button
2. All answers hide
3. Click any question to flip
4. See answer with animation
5. Toggle back to normal mode
```

### 📝 Study Notes

```
1. Click "📝 Note" on any question
2. Write your personal notes
3. Click Save
4. Notes appear below answer
5. Edit/delete anytime
```

### 📊 Statistics

```
1. Click "📊 Stats" in navbar
2. View study time, visits, streak
3. See questions learned count
4. Track progress over time
```

### 🌙 Dark Mode (Press D)

```
1. Press 'D' key
2. Or click theme toggle (top-right)
3. Entire site switches theme
4. Preference saved in browser
```

### ⏱️ Study Timer

```
1. Click preset time (25/5/15/50 min)
2. Click Start
3. Timer counts down
4. Pause or Reset anytime
5. Notification when done
```
