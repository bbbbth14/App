C Interview Questions & Answers

📚 Basic Concepts

What is C programming language?

C is a general-purpose, procedural programming language developed by Dennis Ritchie at Bell Labs in 1972. It is one of the most widely used programming languages and has influenced many other languages like C++, Java, and Python. C is known for its efficiency, low-level memory access, and portability across different platforms.

What are the key features of C?

Key features of C include:
  • Simplicity: Easy to learn with a small set of keywords
  • Efficiency: Produces fast and efficient code
  • Portability: Programs can run on different platforms with minimal changes
  • Low-level access: Direct access to memory through pointers
  • Modularity: Supports functions for code reusability
  • Extensibility: Can add custom functions to libraries

What is the difference between #include <stdio.h> and #include "stdio.h"?

  • #include <stdio.h> - Searches for the header file in the standard system directories first
  • #include "stdio.h" - Searches for the header file in the current directory first, then in the standard system directories
Use angle brackets for standard library headers and double quotes for user-defined headers.
🔢 Data Types & Variables

What are the basic data types in C?

The basic data types in C are:
  • int - Integer numbers (typically 4 bytes)
  • char - Single character (1 byte)
  • float - Single precision floating-point (4 bytes)
  • double - Double precision floating-point (8 bytes)
  • void - Represents no value
These can be modified with short, long, signed, and unsigned.

What is the difference between const and #define?

  • #define is a preprocessor directive that creates a macro. It has no type and simply replaces text before compilation.
  • const creates a typed constant variable that exists in memory and has scope rules.
#define PI 3.14159    // Macro - no type checking
const double PI = 3.14159;  // Typed constant
const is generally preferred for type safety and debugging.
🎯 Pointers

What is a pointer in C?

A pointer is a variable that stores the memory address of another variable. Pointers are declared using the * operator and the address of a variable is obtained using the & operator. 
int num = 10;
int *ptr = &num;  // ptr stores the address of num
printf("%d", *ptr);  // Dereference: prints 10

What is a NULL pointer?

A NULL pointer is a pointer that points to nothing (address 0). It is used to indicate that the pointer is not pointing to any valid memory location. Always initialize pointers to NULL if they don't have a valid address yet. 
int *ptr = NULL;  // Good practice
if (ptr != NULL) {
    // Safe to dereference
}

What is the difference between *ptr++ and ++*ptr?

  • *ptr++ - Returns the value at ptr, then increments the pointer address
  • ++*ptr - Increments the value pointed to by ptr, then returns it
int arr[] = {10, 20, 30};
int *ptr = arr;
printf("%d\n", *ptr++);  // Prints 10, ptr now points to arr[1]
printf("%d\n", ++*ptr);  // Increments arr[1] to 21, prints 21
💾 Memory Management

What is the difference between malloc() and calloc()?

Both functions allocate memory dynamically, but with differences:
  • malloc(size) - Allocates specified bytes, memory contains garbage values
  • calloc(n, size) - Allocates memory for n elements of specified size, initializes to zero
// Allocate memory for 5 integers
int *arr1 = (int *)malloc(5 * sizeof(int));  // Not initialized
int *arr2 = (int *)calloc(5, sizeof(int));   // Initialized to 0

What is a memory leak?

A memory leak occurs when dynamically allocated memory is not freed after use. This causes the program to consume more memory over time, potentially leading to system slowdown or crashes. 
void leak_example() {
    int *ptr = (int *)malloc(sizeof(int));
    // Missing: free(ptr);
}  // Memory is leaked when function returns
Always use free() to release dynamically allocated memory.

What is the difference between stack and heap memory?

  • Stack: Used for static memory allocation (local variables, function calls). Memory is automatically managed (allocated/deallocated). Fast access but limited size.
  • Heap: Used for dynamic memory allocation (malloc, calloc). Programmer must manage memory manually. Slower access but larger size.
void example() {
    int stack_var = 10;  // Stack allocation
    int *heap_var = (int *)malloc(sizeof(int));  // Heap allocation
    *heap_var = 20;
    free(heap_var);  // Must free heap memory
}  // stack_var is automatically freed
📊 Arrays & Strings

What is the difference between an array and a pointer?

While arrays and pointers are closely related in C, they have key differences:
  • An array name is a constant pointer to the first element
  • sizeof(array) returns total array size, sizeof(pointer) returns pointer size
  • Array names cannot be reassigned; pointers can
int arr[5] = {1, 2, 3, 4, 5};
int *ptr = arr;
printf("%zu\n", sizeof(arr));  // 20 (5 * 4 bytes)
printf("%zu\n", sizeof(ptr));  // 8 (pointer size on 64-bit)

How do strings work in C?

In C, strings are arrays of characters terminated by a null character ('\0'). There is no built-in string type. 
char str1[] = "Hello";  // Compiler adds '\0' automatically
char str2[6] = {'H', 'e', 'l', 'l', 'o', '\0'};

// String functions from string.h
strlen(str1);      // Length (5)
strcpy(dest, src); // Copy string
strcmp(s1, s2);    // Compare strings
strcat(s1, s2);    // Concatenate strings
⚙️ Functions

What is the difference between call by value and call by reference?

  • Call by value: A copy of the argument is passed. Changes inside the function don't affect the original variable.
  • Call by reference: The address of the argument is passed. Changes inside the function affect the original variable.
void byValue(int x) { x = 100; }  // Original unchanged
void byReference(int *x) { *x = 100; }  // Original changed

int num = 10;
byValue(num);       // num is still 10
byReference(&num);  // num is now 100

What is a recursive function?

A recursive function is a function that calls itself to solve a problem by breaking it into smaller subproblems. Every recursive function needs a base case to stop the recursion. 
int factorial(int n) {
    if (n <= 1) return 1;  // Base case
    return n * factorial(n - 1);  // Recursive call
}
// factorial(5) = 5 * 4 * 3 * 2 * 1 = 120
🏗️ Structures & Unions

What is a structure in C?

A structure is a user-defined data type that groups related variables of different types under a single name. 
struct Student {
    char name[50];
    int age;
    float gpa;
};

struct Student s1 = {"John", 20, 3.5};
printf("Name: %s, Age: %d", s1.name, s1.age);

What is the difference between structure and union?

  • Structure: All members have their own memory locations. Size = sum of all member sizes (plus padding).
  • Union: All members share the same memory location. Size = size of largest member.
struct S { int i; char c; };  // Size: 8 bytes (with padding)
union U { int i; char c; };   // Size: 4 bytes (size of int)
Use unions when you need to store different types but only one at a time.
📁 File Handling

How do you read and write files in C?

C uses file pointers and functions from stdio.h for file operations: 
// Writing to a file
FILE *fp = fopen("data.txt", "w");
if (fp != NULL) {
    fprintf(fp, "Hello, World!");
    fclose(fp);
}

// Reading from a file
FILE *fp = fopen("data.txt", "r");
if (fp != NULL) {
    char buffer[100];
    while (fgets(buffer, 100, fp) != NULL) {
        printf("%s", buffer);
    }
    fclose(fp);
}
File modes: "r" (read), "w" (write), "a" (append), "r+" (read/write), "w+" (read/write, truncate).
🚀 Advanced Topics

What is a static variable?

A static variable retains its value between function calls. It is initialized only once and exists for the lifetime of the program. 
void counter() {
    static int count = 0;  // Initialized once
    count++;
    printf("Count: %d\n", count);
}
counter();  // Count: 1
counter();  // Count: 2
counter();  // Count: 3

What is the volatile keyword?

The volatile keyword tells the compiler that a variable's value may change unexpectedly (e.g., by hardware or another thread). This prevents the compiler from optimizing reads/writes to that variable. 
volatile int sensor_value;  // May change by hardware
// Compiler will always read from memory, not cache
Common uses: hardware registers, signal handlers, multi-threaded programming.

What is a function pointer?

A function pointer is a pointer that stores the address of a function. It can be used to call functions indirectly. 
int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }

int (*operation)(int, int);  // Function pointer declaration
operation = add;
printf("%d\n", operation(5, 3));  // Prints 8
operation = subtract;
printf("%d\n", operation(5, 3));  // Prints 2
Function pointers are useful for callbacks and implementing polymorphism in C.

What is the difference between ++i and i++?

  • ++i (pre-increment): Increments i first, then returns the new value
  • i++ (post-increment): Returns the current value of i, then increments it
int i = 5;
printf("%d\n", ++i);  // Prints 6, i is now 6
printf("%d\n", i++);  // Prints 6, i becomes 7
printf("%d\n", i);    // Prints 7
🔥 Expert Level Questions

What is a dangling pointer?

A dangling pointer is a pointer that references memory that has been freed or deallocated. Accessing a dangling pointer leads to undefined behavior. 
int *ptr = (int *)malloc(sizeof(int));
*ptr = 10;
free(ptr);      // Memory is freed
// ptr is now a dangling pointer
*ptr = 20;      // DANGEROUS: Undefined behavior

// Solution: Set pointer to NULL after freeing
free(ptr);
ptr = NULL;

What is pointer arithmetic?

Pointer arithmetic allows you to perform mathematical operations on pointers. When you add or subtract from a pointer, it moves by the size of the data type it points to. 
int arr[] = {10, 20, 30, 40, 50};
int *ptr = arr;

printf("%d\n", *ptr);       // 10
printf("%d\n", *(ptr + 1)); // 20
printf("%d\n", *(ptr + 2)); // 30

ptr++;  // Moves 4 bytes (sizeof(int))
printf("%d\n", *ptr);       // 20

What is the difference between realloc() and malloc()?

  • malloc() allocates a new block of memory
  • realloc() resizes an existing memory block, preserving the data
int *arr = (int *)malloc(5 * sizeof(int));
// arr has space for 5 integers

arr = (int *)realloc(arr, 10 * sizeof(int));
// arr now has space for 10 integers
// Original 5 values are preserved
If realloc fails, it returns NULL and the original memory is unchanged.

What is a void pointer?

A void pointer (void *) is a generic pointer that can hold the address of any data type. It must be cast to the appropriate type before dereferencing. 
void *ptr;
int num = 10;
float f = 3.14;

ptr = &num;
printf("%d\n", *(int *)ptr);    // Cast to int*

ptr = &f;
printf("%.2f\n", *(float *)ptr); // Cast to float*
Void pointers are commonly used in functions like malloc() and generic data structures.

What is a double pointer (pointer to pointer)?

A double pointer stores the address of another pointer. It's commonly used for dynamic 2D arrays and modifying pointer values in functions. 
int num = 10;
int *ptr = &num;
int **dptr = &ptr;

printf("%d\n", **dptr);  // 10

// Modifying pointer in function
void allocate(int **p) {
    *p = (int *)malloc(sizeof(int));
    **p = 100;
}

int *myPtr = NULL;
allocate(&myPtr);  // myPtr now points to allocated memory

What is the extern keyword?

The extern keyword declares a variable or function that is defined in another file. It tells the compiler that the definition exists elsewhere. 
// file1.c
int globalVar = 100;

// file2.c
extern int globalVar;  // Declaration, not definition
printf("%d\n", globalVar);  // Uses variable from file1.c
extern is essential for sharing variables across multiple source files.

What is the register keyword?

The register keyword suggests to the compiler that a variable should be stored in a CPU register for faster access. However, modern compilers often ignore this hint and optimize automatically. 
register int counter;
for (counter = 0; counter < 1000000; counter++) {
    // Fast loop variable
}
Note: You cannot take the address of a register variable using &.

What is a bit field in structures?

Bit fields allow you to specify the number of bits a structure member should occupy. They're useful for memory optimization and hardware programming. 
struct PackedData {
    unsigned int flag1 : 1;   // 1 bit
    unsigned int flag2 : 1;   // 1 bit
    unsigned int value : 6;   // 6 bits (0-63)
};  // Total: 1 byte instead of 12 bytes

struct PackedData data;
data.flag1 = 1;
data.flag2 = 0;
data.value = 42;

What is the difference between typedef and #define?

  • typedef creates an alias for a type, processed by the compiler with type checking
  • #define is a preprocessor macro that does text replacement
typedef int* IntPtr;
#define INT_PTR int*

IntPtr a, b;      // Both are int pointers
INT_PTR c, d;     // c is int*, d is just int!

// typedef is safer and more readable

What is an inline function?

An inline function suggests to the compiler to insert the function's code directly at the call site, avoiding function call overhead. 
inline int square(int x) {
    return x * x;
}

int result = square(5);
// Compiler may replace with: int result = 5 * 5;
Use inline for small, frequently called functions. The compiler may ignore the hint for complex functions.

What is recursion vs iteration? When to use which?

  • Recursion: Function calls itself. Elegant for tree/graph problems, but uses more memory (stack frames).
  • Iteration: Uses loops. More memory efficient, better for simple repetitive tasks.
// Recursion
int factorial_rec(int n) {
    return (n <= 1) ? 1 : n * factorial_rec(n - 1);
}

// Iteration
int factorial_iter(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) result *= i;
    return result;
}
Use recursion for naturally recursive problems (trees, backtracking). Use iteration for performance-critical code.

What is a segmentation fault?

A segmentation fault (segfault) occurs when a program tries to access memory it doesn't have permission to access. 
// Common causes:
int *ptr = NULL;
*ptr = 10;  // Dereferencing NULL pointer

int arr[5];
arr[10] = 1;  // Array index out of bounds

char *str = "Hello";
str[0] = 'h';  // Modifying string literal
Debug using tools like gdb or valgrind.
📝 Multiple Choice Questions

What is the size of int in C?

  • A) Always 2 bytes
  • B) Always 4 bytes
  • C) Always 8 bytes
  • D) Depends on the compiler and system architecture
Answer: D - The size of int is implementation-defined. It's typically 4 bytes on modern systems, but can be 2 bytes on older systems. Use sizeof(int) to check.

What will be the output of: printf("%d", 5 + 3 * 2);

  • A) 16
  • B) 11
  • C) 13
  • D) Error
Answer: B - Multiplication has higher precedence than addition. So 3 * 2 = 6, then 5 + 6 = 11.

Which of the following is NOT a valid variable name in C?

  • A) _myVar
  • B) my_var
  • C) 2ndValue
  • D) myVar2
Answer: C - Variable names cannot start with a digit in C. They must start with a letter or underscore.

What does NULL represent in C?

  • A) An empty string
  • B) The character '\0'
  • C) A null pointer constant (typically 0)
  • D) An undefined value
Answer: C - NULL is a macro that represents a null pointer constant. It's typically defined as ((void *)0) or just 0.

What is the output of: printf("%d", sizeof('A'));

  • A) 1
  • B) 4
  • C) 2
  • D) 8
Answer: B - In C, character constants like 'A' are treated as int, so sizeof returns 4 (on most systems). In C++, it would return 1.

Which storage class is used to define a local variable that retains its value?

  • A) auto
  • B) extern
  • C) static
  • D) register
Answer: C - Static variables retain their value between function calls. They are initialized only once.

What is the correct way to declare a pointer to an integer?

  • A) int ptr;
  • B) *int ptr;
  • C) int *ptr;
  • D) pointer int ptr;
Answer: C - The asterisk (*) is placed before the variable name to declare a pointer. int *ptr declares ptr as a pointer to an integer.

What is the output of: int x = 5; printf("%d", x++);

  • A) 5
  • B) 6
  • C) 4
  • D) Error
Answer: A - Post-increment (x++) returns the current value first, then increments. So it prints 5, and x becomes 6 after.

Which function is used to dynamically allocate memory and initialize it to zero?

  • A) malloc()
  • B) calloc()
  • C) realloc()
  • D) free()
Answer: B - calloc() allocates memory and initializes all bytes to zero. malloc() allocates memory but doesn't initialize it.

What is the output of: printf("%d", 10 / 3);

  • A) 3
  • B) 3.33
  • C) 3.0
  • D) 4
Answer: A - Integer division in C truncates the decimal part. 10 / 3 = 3 (not 3.33). For decimal result, use float: 10.0 / 3.

What does the break statement do in a loop?

  • A) Skips current iteration
  • B) Exits the loop immediately
  • C) Restarts the loop
  • D) Pauses the loop
Answer: B - break immediately exits the innermost loop or switch statement. Use continue to skip only the current iteration.

Which header file is required for malloc() and free()?

  • A) stdio.h
  • B) stdlib.h
  • C) string.h
  • D) memory.h
Answer: B - Memory allocation functions (malloc, calloc, realloc, free) are declared in stdlib.h.

What is the correct syntax for a multi-line comment in C?

  • A) // comment //
  • B) /* comment */
  • C) <!-- comment -->
  • D) # comment #
Answer: B - Multi-line comments use /* */. Single-line comments use // (C99 and later).

What is the result of: int a = 5, b = 2; float c = a / b;

  • A) c = 2.0
  • B) c = 2.5
  • C) c = 2
  • D) Compilation error
Answer: A - Integer division happens first (5/2 = 2), then the result is converted to float (2.0). For 2.5, cast one operand: (float)a / b.

Which operator is used to access a structure member through a pointer?

  • A) . (dot)
  • B) -> (arrow)
  • C) * (asterisk)
  • D) & (ampersand)
Answer: B - The arrow operator (->) is used with pointers to structures. Dot (.) is used with structure variables directly.
